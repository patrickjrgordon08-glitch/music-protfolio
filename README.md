# Northline Audio

A responsive producer portfolio and booking-inquiry site. Project cards open credit details, and the booking form prepares an email draft on the visitor's device.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite.

## Before publishing

- Replace the sample project names, credits, descriptions, availability, and brand copy with real details.
- Set `bookingEmail` in `src/App.tsx` to a monitored address. The form does not send data to a server.
- The studio photo in `public/abbey-road-studio2.jpg` shows Abbey Road Studio 2 in 2010. It is by David Boyle and licensed under CC BY 2.0. Replace it with your own photo if it is not appropriate for your brand.

## Validate

```sh
npm run build
npm run lint
```
